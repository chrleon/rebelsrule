Rebels Rule

A Rebelle-style ruler: drop an anchor, then every stroke you drag is locked to the straight line through the anchor and the point where the stroke starts.

Using it

  • Ctrl+Alt+R or Tools → Scripts → Rebels Rule turns it on and off.
  • Tap the canvas to place the anchor. Tap again to move it.
  • Drag to paint along the line. Pressure, tilt and rotation still apply.
  • Esc clears the anchor.
  • Strokes with Ctrl, Shift, Alt or Space held, and other pen buttons, behave normally.

Development

Ctrl+Alt+Shift+R (Reload Rebels Rule) re-imports the ruler code from disk without restarting Krita.
